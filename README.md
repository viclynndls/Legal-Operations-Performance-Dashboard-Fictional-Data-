# Legal Operations Performance Dashboard (Fictional Data)
*A Portfolio Simulation Project Built in Power BI*

## 📌 Summary

This repository contains an end-to-end Power BI dashboard designed to simulate the performance analytics needed in a large personal injury law firm such as Jacoby & Meyers. All data is synthetic and was created strictly for portfolio use.

The project includes:

- Multi-table star-schema data model

- KPI metrics (settlement rate, stuck cases, case duration)

- Attorney workload analysis

- Intake performance & funnel tracking

- Custom branded theme

- Four fully formatted dashboard pages

## 📊 Dashboard Pages
### 1. Firmwide Performance Dashboard

- Total cases

- Settlement rate

- Avg case duration

- Case volume trend

- Cases by type


### 2. Intake and Conversion

- Total leads

- Leads by source

- Intake approval rate

- Avg intake → assignment days

- Lead-to-case funnel visualization

### 3. Attorney Workload

- Average caseload

- Settlement rate by attorney

- Avg duration by attorney

- Attorney slicer

### 3. Case Pipeline and Bottlenecks

- Current Stage caseload

- Percent stuck per stage

- Avg days per stage


## 🧠 Key DAX Measures

- Total Cases

- Settlement Rate

- Funnel Logic (Lead → Intake → Approved → Assigned)

- Avg Case Duration
